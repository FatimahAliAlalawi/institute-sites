# موقع ومنصة معهد البصائر العالي للتدريب

موقع المعهد ونظام تشغيله الداخلي في مكان واحد: موقع تعريفي، ومنصة تعليمية، ونظام كامل لإدارة **دورات الأفراد الحضورية** من التخطيط والإعلان حتى التحضير والشهادة، مع لوحة تحكم عربية وصلاحيات لكل موظف.

- **التقنية:** Laravel 12، PHP 8.2 أو أحدث، MySQL / MariaDB.
- **الاستضافة:** cPanel بدون SSH ولا Composer (ملف التحديث يُبنى مع مجلد `vendor`).
- **الواجهة:** عربية بالكامل (RTL) بهوية المعهد: البنفسجي `#32255D` والأزرق `#1E99D1`.

## نظرة عامة على الأقسام

| القسم | ماذا يقدّم |
|---|---|
| **الموقع التعريفي** | الرئيسية، من نحن، البرامج، الأخبار، تواصل معنا، صفحات وقوائم قابلة للتعديل، شريط إعلان. |
| **الخطة التدريبية للأفراد** | صفحة عامة `/plan` تعرض الدورات المعتمدة لثلاثة أشهر حسب الشهر، بالأسعار والخصومات والمقاعد المتبقية. |
| **اعتماد الإدارة** | لا تظهر دورة في الخطة ولا يُنشر إعلان إلا باعتماد الإدارة، وأي تعديل على بيانات معتمدة يعيدها للانتظار. |
| **بطاقة الإعلان و QR** | كل بيانات الإعلان المعتمدة في صفحة واحدة للمصمم، مع رمزي QR (التسجيل وواتساب) بروابط قصيرة ثابتة. |
| **قائمة المتابعة** | «طلبات التسجيل» هي قائمة المهتمين: الحالة، المصدر، موعد المتابعة، رقم الفاتورة، تأكيد الحضور، كود الخصم. |
| **المقاعد** | عدّ المسجلين مقابل المقاعد، ومنع القبول فوق العدد، وإغلاق التسجيل تلقائيًا عند الاكتمال. |
| **تشغيل الدورة** | خطوات «آلية التسجيل» التسع لكل دورة بالمسؤولين والمواعيد، ومتابعة كل متدرب، وإرسال الرسائل. |
| **رسائل المتدربين** | ست رسائل ثابتة قابلة للتعديل، تُرسل بالإيميل لكل الدورة أو تُفتح جاهزة في واتساب لكل متدرب. |
| **التحضير والتقويم** | تحضير يومي للدورات الحضورية، وتقويم شهري، وملف «أضف للتقويم» للجوال. |
| **المهام ومتابعة الفريق** | «مهامي» لكل موظف، و«متابعة الفريق» للإدارة: وين وصلت العملية عند كل موظف وفي كل دورة. |
| **نقل المتقدمين** | ربط مؤقت بجدول ردود نموذج Google (سحب تلقائي) أو رفع ملف Excel، مع منع التكرار. |
| **المنصة التعليمية** | دورات مسجلة ومباشرة (Zoom)، دروس يومية، اختبارات، شهادات بتحقق، حسابات طلاب. |
| **المدفوعات** | تحويل بنكي مع رفع الإيصال، ودفع إلكتروني عبر ميسر (مدى، فيزا، Apple Pay، STC Pay)، وكوبونات خصم. |

## رحلة دورة الأفراد في النظام

مطابقة للدليل التشغيلي لدورات الأفراد:

```
0. الخطة       مسؤول التدريب يُدخل الدورة (تاريخ، سعر، رقم اعتماد) ← «إرسال للإدارة للاعتماد»
               الإدارة تعتمد من «اعتماد الخطة والإعلانات» ← تظهر في /plan
1-3. الإعلان   التسويق يفتح «بطاقة الإعلان و QR» ← يصمم ← يرسل للاعتماد ← الإدارة تعتمد
4-5. التسويق   كل مهتم يُضاف في «طلبات التسجيل» (أو يصل من الموقع / نموذج Google)
               ← «متابعات اليوم» تقول لك مين تتابع
6-7. التسجيل   كتابة رقم الفاتورة = اعتماد التسجيل: يُقبل المتدرب ويُحجز له مقعد تلقائيًا
8-11. قبل الدورة «تشغيل الدورة»: رسالة التأكيد + رابط المجموعة، الترحيب، جدول التحضير، القاعة،
               تذكير قبل يوم (تلقائي بالإيميل)، تذكير الصباح (تلقائي)
12-13. الدورة  المدرب يحضّر من حسابه، والإضافة في نظام المؤسسة، وتقرير الحضور للمتدرب
14-15. بعدها   رسالة الشكر وكود الخصم، وحالة «أكمل الدورة»
```

## لوحة التحكم

الرابط: `/admin`. القائمة الجانبية تُظهر لكل موظف الأقسام المسموحة له فقط.

### دورات الأفراد

| الشاشة | الاستخدام |
|---|---|
| **مهامي** | مهام الموظف المسندة باسمه في كل دورة (المتأخر بالأحمر، واليوم بالبرتقالي)، ومتابعات المهتمين المستحقة. |
| **متابعة الفريق** | لكل موظف: المفتوح، المتأخر، المنجز، ونسبة الإنجاز. وجدول لكل دورة يوضح وين وصلت كل خطوة. |
| **البرامج التدريبية** | بيانات الدورة: الاسم المعتمد، رقم الاعتماد، المدة، الأيام والوقت، المدرب وحسابه، تقويم أيام الدورة، الرسوم والخصم وتاريخ انتهائه، المقاعد، حالة الخطة والإعلان. |
| ↳ **تشغيل الدورة** | الخطوات التسع بالمسؤول والموعد والإنجاز، ورابط مجموعة واتساب، وجدول كل متدرب مع أزرار واتساب وأزرار الإرسال بالإيميل. |
| ↳ **بطاقة الإعلان و QR** | البيانات السبع للإعلان، والتنبيه لأي نقص، وتنزيل رموز QR بصيغة SVG، وعلامة «مسودة» قبل الاعتماد. |
| **اعتماد الخطة والإعلانات** | للإدارة: كل ما ينتظر الاعتماد، مع اعتماد أو رفض بملاحظة. |
| **تحضير الدورات الحضورية** | تقويم شهري بحالة كل يوم، وتحضير (حاضر / متأخر / غائب / بعذر) بملاحظة، وإجمالي حضور كل متدرب. |
| **طلبات التسجيل** | قائمة المتابعة: تبويب «متابعات اليوم»، تبويب لكل حالة، فلتر الدورة والمصدر، شريط المقاعد، «إضافة مهتم»، تصدير Excel. |
| ↳ **نقل من نموذج Google / Excel** | ربط جدول الردود، سحب تلقائي كل 15 دقيقة، رفع ملف xlsx أو CSV، ربط الأعمدة، حالة المتقدمين الجدد. |

### حالات طلب التسجيل

| الحالة | المعنى | تحجز مقعدًا |
|---|---|---|
| جديد (سأل) | مهتم لم يُرد عليه بعد | لا |
| تم التواصل (أرسلنا العرض) | أُرسل له العرض، والمتابعة بعد يومين تلقائيًا | لا |
| لم يرد | آخر متابعة قبل انتهاء العرض | لا |
| **مقبول (سجّل ودفع)** | دفع واعتُمدت فاتورته | **نعم** |
| أكمل الدورة | أنهى الدورة | نعم |
| اعتذر / انسحب | يفك المقعد | لا |
| غير مقبول | — | لا |

### خطوات آلية التسجيل (تشغيل الدورة)

| # | الخطوة | النوع | الموعد |
|---|---|---|---|
| 01 | تسجيل المتدرب | لكل متدرب | عند التسجيل |
| 02 | إنشاء الفاتورة | لكل متدرب | عند التسجيل |
| 03 | إرسال الفاتورة + رابط المجموعة | لكل متدرب | عند التسجيل |
| 04 | رسالة ترحيبية | لكل متدرب | عند التسجيل |
| 05 | إنشاء جدول التحضير | للدورة | قبلها بـ 3 أيام |
| 06 | تجهيز القاعة والملازم | للدورة | قبلها بـ 3 أيام |
| 07 | رسالة تذكير | لكل متدرب | قبلها بيوم |
| 08 | تذكير صباح الدورة | لكل متدرب | يوم الدورة |
| 09 | إضافة الأسماء في المؤسسة | لكل متدرب | يوم الدورة |

المسؤول عن كل خطوة يُكتب بالاسم كما في حساب الموظف، ويُحفظ افتراضيًا لكل الدورات. المطابقة تكون بالاسم الكامل أو الاسم الأول، وتظهر بجانب كل اسم الحسابات المربوطة به.

### رسائل المتدربين

| الرسالة | تُرسل |
|---|---|
| التأكيد مع الفاتورة ورابط المجموعة ورابط التقويم | بعد اعتماد الفاتورة |
| الترحيب | بعد التسجيل |
| التذكير قبل الدورة بيوم | تلقائي بالإيميل بعد 4 العصر، أو يدوي |
| تذكير صباح الدورة | تلقائي بالإيميل من 7 صباحًا، أو يدوي |
| تقرير الحضور | من «تشغيل الدورة» في أي وقت |
| الشكر بعد الدورة | بعد آخر يوم |

**المتغيرات:** `{الاسم}` `{الاسم_الكامل}` `{الدورة}` `{رقم_الاعتماد}` `{التاريخ}` `{الأيام}` `{الوقت}` `{المدرب}` `{المكان}` `{رابط_المجموعة}` `{رقم_الفاتورة}` `{رقم_المعهد}` `{المعهد}` `{رابط_الخطة}` `{رابط_التقويم}` `{أيام_الحضور}` `{أيام_الدورة}` `{ملاحظة_الحضور}`

**عن واتساب:** الزر يفتح واتساب والرسالة مكتوبة جاهزة، والإرسال بضغطة من الموظف. الإرسال الآلي الكامل يحتاج ربطًا بخدمة WhatsApp Business API من Meta.

## الأدوار والصلاحيات

من «المستخدمون والصلاحيات»: أنشئ دورًا واختر صلاحياته، ثم أنشئ حساب الموظف بهذا الدور. المدير العام يملك كل الصلاحيات.

| الصلاحية | تفتح |
|---|---|
| البرامج التدريبية | البرامج، تشغيل الدورة، بطاقة الإعلان |
| اعتماد الخطة التدريبية والإعلانات ومتابعة الفريق | الاعتمادات، متابعة الفريق |
| طلبات التسجيل | قائمة المتابعة، نقل من نموذج Google / Excel |
| تحضير الدورات الحضورية (للمدربين) | التحضير والتقويم |
| كوبونات الخصم وشريط الإعلان | الكوبونات |
| إعدادات الموقع | الإعدادات، البريد، قوالب الرسائل |
| المستخدمون والصلاحيات | الحسابات والأدوار |
| (وصلاحيات المنصة التعليمية والمحتوى الأخرى) | |

**أدوار مقترحة:**

| الدور | الصلاحيات |
|---|---|
| الإدارة | اعتماد الخطة والإعلانات ومتابعة الفريق + ما تحتاجه |
| مسؤول التدريب | البرامج التدريبية + طلبات التسجيل + تحضير الدورات الحضورية |
| التسويق | البرامج التدريبية + كوبونات الخصم |
| خدمة العملاء والتسجيل | طلبات التسجيل + البرامج التدريبية |
| **المدرب** | **تحضير الدورات الحضورية فقط** ← يرى دوراته المربوطة بحسابه فقط |

«مهامي» متاحة لكل موظف بدون صلاحية خاصة.

## الإعدادات المهمة بعد التثبيت

من **إعدادات الموقع**:

1. **التواصل:** رقم الهاتف وواتساب (يُستخدمان في الإعلانات والرسائل).
2. **البريد الإلكتروني (رسائل المتدربين):** أنشئ بريدًا في cPanel مثل `info@albsaer.com`، ثم اكتب:
   - الخادم (غالبًا `mail.albsaer.com`)، والمنفذ `465`، والبريد وكلمة مروره، واسم المرسل.
   - اضغط «إرسال تجربة» أسفل الصفحة للتأكد.
   - فعّل «تذكير تلقائي بالإيميل» إن أردت.
3. **قوالب رسائل المتدربين:** عدّل نصوص الرسائل الست.
4. **الدفع:** بيانات الحساب البنكي، ومفاتيح ميسر إن وُجدت.

ومن **البرامج التدريبية**: أدخل لكل دورة حساب المدرب وتقويم أيامها، وفي «تشغيل الدورة» أسماء المسؤولين واحفظها كافتراضي.

## التثبيت والتحديث على cPanel

### التثبيت لأول مرة
التفاصيل في [INSTALL-AR.md](INSTALL-AR.md). باختصار:
1. أنشئ قاعدة بيانات MySQL ومستخدمًا بكل الصلاحيات.
2. ارفع الملفات في جذر الدومين وفك الضغط.
3. افتح `/install` وأدخل بيانات القاعدة وحساب المدير.

### التحديث
1. خذ نسخة احتياطية من الملفات وقاعدة البيانات.
2. ارفع ملف التحديث `albasaer-laravel-update.zip` في نفس مجلد الموقع وفك الضغط مع **استبدال الملفات**. الملف لا يحتوي `.env` ولا ملفات المستخدمين، فلا يمسّها.
3. افتح الموقع: الجداول الجديدة تُنفّذ تلقائيًا عند أول زيارة (`App\Support\SchemaUpdater`) بدون فقدان بيانات.

> أي تغيير في قاعدة البيانات يكون **ملف migration جديدًا** في `database/migrations` (لا يُعدّل القديم).

### التحديثات الأخيرة على قاعدة البيانات

| الملف | يضيف |
|---|---|
| `2026_01_11_..._add_training_plan_to_programs` | رقم الاعتماد، الخصم وتاريخ انتهائه، رقم التواصل، اعتماد الخطة والإعلان، رابط «خطة الأفراد» في القائمة |
| `2026_01_12_..._add_follow_up_to_registrations` | المصدر، موعد المتابعة، رقم الفاتورة، تأكيد الحضور، كود الخصم |
| `2026_01_13_..._add_course_ops` | أيام ووقت الدورة، المدرب، رابط المجموعة، خطوات التشغيل، المسؤولون الافتراضيون |
| `2026_01_14_..._create_program_attendances` | جدول التحضير |
| `2026_01_15_..._add_trainer_and_sessions_to_programs` | حساب المدرب وتقويم أيام الدورة |

```
php /home/USERNAME/public_html/artisan trainees:remind
```

## الخصوصية والأمان

- ملف `.env` (كلمة مرور قاعدة البيانات ومفتاح الموقع) **لا يُرفع** إلى GitHub ولا يدخل في ملف التحديث.
- كلمات المرور السرية في الإعدادات (البريد، ميسر، Zoom) تُحفظ ولا تُعرض مرة أخرى.
- الملفات التي يرفعها الطلاب (الإيصالات والمرفقات) تبقى على السيرفر فقط خارج المستودع.
